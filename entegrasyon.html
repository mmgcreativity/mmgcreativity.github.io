Nasıl çalışır? 3 seviye

İhtiyacınıza ve programınızın sürümüne göre üç entegrasyon seviyesinden birini seçebilirsiniz:

1
Excel / XML Aktarımı Hemen · Lisanssız
Verinizi Excel/XML olarak dışa aktarır, Logo/Zirve'nin içe aktarım ekranından yüklersiniz. Ek altyapı, API veya lisans gerektirmez.
2
REST API ile Canlı Senkron API Key gerekir
Program bir REST API sunuyorsa (Logo j-Platform, Logo İşbaşı, Zirve) verileriniz otomatik ve çift yönlü senkronize edilir. API bilgileri + bir sunucu bağlantısı gerekir.
3
Yerel Köprü (Agent) + SQL Yerel kurulum
Program kendi sunucunuzda (MS SQL Server) çalışıyorsa, küçük bir yerel köprü programı Logo/Zirve veritabanı ile bulut arasında bağ kurar. En güçlü, en çok kurulum isteyen yol.

Adım adım — Excel/XML ile aktarım (bugün yapabilirsiniz)

  1. Dijital Finans Asistanı'nda Gelirler / Giderler / Nakit Akış ekranından “Excel'e Aktar” ile verinizi indirin.
  2. Logo veya Zirve'de içe aktarım / Express Aktarım ekranını açın.
  3. Kolon eşlemesini yapın (tarih, tutar, cari/hesap kodu, açıklama). Cari/hesap kodlarının iki tarafta da tekil ve aynı olması şarttır.
  4. Aktarımı çalıştırın; kayıtlar muhasebe fişi olarak oluşur.
İstерseniz çıktı formatını doğrudan sizin Logo/Zirve içe aktarım şablonunuza birebir uyacak şekilde hazırlayabiliriz — böylece kolon eşlemesiyle uğraşmazsınız.

Canlı (API) entegrasyon için gerekenler

  • Program sürümü: j-Platform / Tiger-GO 3-Wings / İşbaşı / Zirve.
  • API erişimi: API Key / kullanıcı-şifre (Logo İşbaşı, Zirve) veya REST Servis + lisans (Tiger/j-Platform).
  • Sunucu erişimi: Yerel kurulumda SQL Server erişimi ya da REST Servis'in açık olması.
  • Eşleme anahtarları: cari, hesap ve ürün kodlarının tekil olması.

Bu bilgiler tamam olduğunda, verinizi otomatik ve çift yönlü senkronize eden bir bağlantı kurarız.
